# When Redlands discovers Luke Hayes

Music, personal intelligence and whole systems change.

A thought experiment by Luke Nathan Hayes about Redlands encountering his connected body of work, P4A satire and i C. infinity music, a first Aura Genesis programme, HBOT and the proposed Geode, and a fair go in the age of superintelligence. No decision to run for mayor is announced.

**Website edition:** 1.0.1 · 16 October 2026  
**Source document:** Version 4.0, with its earlier revision history retained.

## Hosting

Static HTML, CSS and JavaScript, with no build step or third-party runtime dependencies. GitHub Pages serves the `main` branch at the repository root. Relative file paths support project-site hosting. `.nojekyll` keeps the static assets unchanged.

`robots.txt`, `sitemap.xml`, canonical metadata and `llms.txt` support discovery. Indexing is controlled by search providers. If the repository is renamed, update canonical URLs and these files together.

## Artwork

Each page has original AI-generated concept artwork. The images represent ideas and imagined settings; they are not photographs of operating facilities. Asset provenance and prompts are recorded in `assets/images/provenance.json`.
